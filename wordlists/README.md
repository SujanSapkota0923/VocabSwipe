# Word files

Ready-to-upload files in the format described in the main `README.md`.

| File | Contents |
| --- | --- |
| `pte_words_with_meanings.csv` | 812 PTE words, each with up to three meanings. Plays immediately. |
| `pte_advanced_words.csv` | 3,153 bare words (header `word`) from the APEUni PTE Advanced list. Meanings are looked up after upload. |
| `sample_words_only.txt` | 10 bare words, for a quick test of the meaning lookup. |

The APEUni list comes from a third-party study guide. Check its terms before
publishing it as part of a public repository.
